PROJECT SHREDDED 2027 - Samsung Galaxy S25 Ultra

1. Extract the ZIP. Open index.html in a browser to try the tracker.
2. For full installable PWA/offline support, upload all four files in the shredded2027 folder to an HTTPS static host (e.g. GitHub Pages or Netlify). Keep files in the same directory.
3. Open the HTTPS URL in Chrome on your S25 Ultra; choose menu > Add to Home screen > Install.
4. Your fitness logs are stored in that browser's local storage for that origin. Data saved on file:// will NOT automatically transfer to the hosted site. Export JSON and import it on the hosted version to transfer records.
5. Notifications in this version are limited to while the page is open; reliable scheduled background notifications require a server-side push system.
6. The workout plan is a reference until lower-back pain has been assessed and movements cleared.
